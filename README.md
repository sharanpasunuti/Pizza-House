# 🍕 Pizza House

A modern, responsive pizza restaurant landing page built using **HTML5** and **CSS3**.

## 📖 About

Pizza House is a frontend practice project that demonstrates modern webpage layout techniques using semantic HTML and CSS. The project focuses on building a clean restaurant landing page with reusable components and responsive design principles.

## ✨ Features

- Responsive Navigation Bar
- Hero Section with Background Image
- Interactive Call-to-Action Buttons
- "Why Choose Us" Feature Cards
- Modern Footer
- Hover Animations
- Flexbox Layout
- Clean Semantic HTML Structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
